- **ARM**: ARMv6, ARMv7 and ARMv8-A, with Cortex-M MCUs including the STM32H7 family
- **ARM Profiles**: Cortex-M (microcontrollers), Cortex-A (application processors running embedded Linux) and the architecture versions behind them (ARMv6-M, ARMv7-M/ARMv7E-M, ARMv8-M, ARMv8-A)
- **Cortex-M Cores in Practice**: Cortex-M4 (Renesas Synergy S7G2), Cortex-M7 + M4 dual-core (STM32H755) and Cortex-M33 (STM32H563)

- **Multicore and Heterogeneous Systems**: asymmetric dual-core designs, inter-core communication and shared memory partitioning
- **Memory Architecture**: Flash, SRAM, TCM, caches, external RAM/ROM interfaces, memory maps and bus matrices
- **Cache and Memory Coherency**: instruction/data cache behaviour, DMA coherency and memory barriers
- **Interrupts and Exceptions**: NVIC, interrupt priorities, vector tables and real-time latency

- **Boot and Startup**: reset sequence, bootloaders, linker scripts and memory-mapped startup code
